# MCP transport calibration

The `MCP_pipeline_calibration_cube.*` files in this folder are exports of Blender's default cube temporarily scaled to 2.5 × 2 × 2 m for the update check; the cube in Blender was restored to its original scale afterward. They are disposable connectivity fixtures, not Halberd source geometry or an approved game asset. Keep them isolated from production imports and use only the dedicated Onshape pilot document and Unity validation area when checking the transfer path.
